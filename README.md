# 가입 에이전트 시나리오 프로토타입

U+ 가입 에이전트(기기변경 탐색 · 가입 · 개통)의 고객 관점 시나리오를 씬별 대화로 자동 재생하는 샘플 화면이에요.
UI는 Figma `가입 에이전트` 파일의 **C안 · 완전 대화형** 화면을 따라요. 금액 · 날짜 · 기종은 모두 예시 값이에요.

## 시나리오

| 번호 | 시나리오 | 엣지 | 단계 |
|---|---|---|---|
| [기본] | 초간편 기변 | 쓰던 그대로, 확인만 하면 가입되게 해줘 | 1단계 |
| ① | 선택 근거 리포트 | 왜 이게 제일 나은지 알려줘 | 1단계 |
| ② | 타이밍 진단 | 더 좋은 날이 있으면, 기다리라고 말해줘 | 1단계 |
| ③ | 숨은 조건 제로 | 나중에 붙는 조건 없이 바꾸게 해줘 | 1단계 |
| ④ | 요금제 다이어트 | 쓰는 만큼만 내게 요금제도 봐줘 | 1단계 |
| ⑤ | 실시간 개통 케어 | 지금 어디쯤인지, 막히면 왜인지 바로 알려줘 | 2·3단계 |
| ⑥ | 혜택 마감 알리미 | 받을 수 있는 혜택, 마감 전에 알려줘 | 개통 이후 |
| ⑦ | 기한 있는 가입 안내 | 나중엔 못 드는 보험, 놓치기 전에 알려줘 | 개통 이후 |

## 실행

빌드 없이 정적 파일만으로 동작해요.

```bash
# 그냥 index.html 을 브라우저로 열어도 되고, 로컬 서버로 띄워도 돼요
npx serve .
# 또는
python3 -m http.server 8000
```

GitHub Pages로 공유하려면 저장소 **Settings → Pages**에서 `main` 브랜치 `/ (root)`를 선택하면 돼요.

## 조작

- 왼쪽 목록에서 시나리오를 고르면 SCENE 1부터 재생, 씬 이름을 누르면 그 씬부터 재생 (앞 씬 대화는 미리 쌓여요)
- 한 시나리오 안의 씬은 대화가 끊기지 않고 이어지고, 마지막 씬 후 다음 시나리오로 넘어가요
- 버튼: 처음부터 · 이전 씬 · 재생/일시정지 · 다음 씬 · 속도(1x / 1.5x / 2x)
- 키보드: `Space` 재생/일시정지, `←` `→` 이전/다음 씬

## 구조

```
index.html          화면 뼈대 (좌측 패널 + 폰 프레임)
src/styles.css      스타일 (폰 내부는 Figma C안 토큰)
src/icons.js        아이콘 SVG
src/scenarios.js    시나리오 · 씬 · 대화 데이터  ← 문구 수정은 여기만
src/app.js          카드 렌더링 · 재생 엔진 · 컨트롤
```

새 시나리오나 씬은 `src/scenarios.js` 배열에 추가하면 돼요. 사용할 수 있는 step·카드 형식은 파일 맨 위 주석에 정리되어 있어요.
